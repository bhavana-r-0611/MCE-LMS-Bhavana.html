Library Management Simulator

Issue, return and reserve books, then move the clock forward to see due dates, fines and reservation holds work. Rules: 3 books per student, 14-day loans, ₹2 per late day, issue blocked above ₹50 unpaid fines, holds last 2 days.

Student information

To add, type a name and choose Add student. To edit, select a student, change the name, department or year, then choose Update selected.

Book information

Typing a title that already exists adds more copies of that book. Syllabus books are named Title (Author) and grouped by semester and subject in the Book list.

Issue and reserve

Try it: issue Software Engineering (one copy) to a student, reserve it for a second student, then return the first loan and watch the copy go on hold.
